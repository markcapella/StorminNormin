## Description

> A colorful drifting falling snowy stormy field that mesmerizes on your desktop.
>
> You'll be warmin, to StorminNormin 🌧️

## Installation.

> KDE, Ubuntu/Gnome, or OpenBox-like Window Managers are supported.
>
> Basically, an X11 based DisplayManager, with TrueColor32 capable
> Window Manager (Kwin, Openbox, Fluxbox, Xfwm4, Mutter/Gnome).
>
> Tiling managers such as Awesome may run but without pointer event
> transparency.

### Install Pre-reqs.

> This is automated. The build system will warn you of missing packages.

### Clone StorminNormin source folder, and cd into it.

    git clone https://github.com/markcapella/StorminNormin
    cd StorminNormin

## Basic development.

### Install.

```bash
./startProj
```
```bash
./buildProj
```
```bash
./installProj
```

### Uninstall.

```bash
./uninstallProj
```
```bash
./cleanProj
rm -rf ~/.config/StorminNormin
```

## Usage after install.

### GUI Desktop.

> Click the StorminNormin desktop icon that's added to your
> systems menu under "Games".

### Command Line.

    StorminNormin
